Animation pause and resume

The pager advances CSS keyframes while the live view is open. Press p to pause or resume from the current point; --pause-animation opens on the initial frame.

p pauses or resumes both markers from the current point.
--pause-animation starts on the initial frame, useful for a still or a review.
--text and snapshots use the initial state; the caption carries the meaning.
What stays static when the animation is paused?

The diagram, title, description, and caption stay readable. Pause only stops the CSS animation clock. The same document still supports search, fragment links, disclosures, and reload.
