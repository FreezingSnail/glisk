Responsive layout

Cards wrap with flexbox as the viewport narrows. There is no horizontal scrolling and no fixed width wider than the pane.

Flex cards

Each card uses flex: 1 1 270px and min-width: 0, so long words wrap instead of forcing the row wider.

Searchable text

Press / and type disclosure, tmux, or reload to search this report. Matches include closed disclosure bodies.

Keyboard and mouse

Tab moves through links and summaries. Left-click follows a fragment link or toggles a disclosure at its rendered position. The wheel or trackpad scrolls.

Disclosures

Open a summary with Enter or a left-click. Search a term inside a closed disclosure and Glisk opens it to reach the match.

Why are external resources denied?

Glisk reads one document and never fetches the network, secondary stylesheets, fonts, images, or scripts. A denied image is skipped; the rest of the report stays readable. The offline-denied fixture in the examples directory exercises this path.

What does the supported tmux workflow require?

One visible tmux 3.5+ pane, one attached Ghostty 1.4+ client, and the pane-local opt-in tmux set-option -p allow-passthrough on. Run Glisk directly in that pane. Glisk never changes tmux settings and falls back to plain text with one diagnostic when the pane or client is unsupported.

How do I keep my place across a live reload?

Give sections, headings, and disclosures stable unique ids. Glisk restores the visible block anchor, open disclosure ids, focus, and the search query after a save or atomic rename. Use --no-watch for a snapshot session that ignores later saves.

Reload-stable ids

This section has an id, and each card below has an id. A regenerated report that keeps them can move content above the reader without losing the reading position.

AnchorThe visible block id is preferred, then the containing section.
